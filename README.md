# 🌐 Advanced Portfolio with CSS Grid

A modern, responsive personal portfolio website built using **HTML5, CSS3, and JavaScript**. This project demonstrates advanced CSS techniques including **CSS Grid, Flexbox, CSS Variables, animations, transitions, responsive design, advanced selectors, and BEM methodology**.

---

## 📌 Project Overview

The **Advanced Portfolio** is designed to showcase my personal information, education, technical skills, projects, and contact details in a professional and interactive way.

The main goal of this project is to demonstrate modern frontend development skills while creating a clean, responsive, and user-friendly portfolio website.

---

## ✨ Features

- 🏠 Responsive Home page
- 👩‍💻 About Me section
- 🎓 Education and skills section
- 💼 Projects showcase
- 📩 Contact form with validation
- 📱 Mobile-first responsive design
- 🎨 CSS Grid for advanced layouts
- 📐 Flexbox for component alignment
- 🎨 CSS Variables for theme management
- 🌙 Dark/Light mode
- ✨ Smooth animations and transitions
- 🖱️ Hover effects
- 🧩 BEM CSS methodology
- 💾 Local Storage for theme preference
- ⚡ Optimized images
- ♿ Accessibility-friendly design
- 📱 Mobile navigation menu
